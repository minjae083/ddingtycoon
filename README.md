# 띵타이쿤 WIKI — 세레니티 제작 레시피 도감

기존 **1000 스테미나 효율 계산기**를 대체하는 새 정적 위키입니다.

## 메뉴 구조

- **강화 연구소 → 강화 제작 시설**
  1. 광물 뭉치
  2. 강화 스톤
  3. 영혼 계약서
  4. 수상한 각인석
- **소담 주방 → 요리 제작 시설 / 황금요리 제작시설**
- **채광 작업장 → 채광물 가공시설**
- **농작물 상회 → 농작물 가공 시설**
- **효율 비교 → 요리 판매가와 직접 제작 재료 비교** (1000 ST 계산 기능 없음)

## GitHub Pages에 적용

1. ZIP 파일을 압축 해제합니다.
2. 압축 해제 폴더 안의 모든 파일과 `assets` 폴더를 저장소 **최상위(root)**에 업로드합니다. ZIP 자체를 업로드하면 안 됩니다.
3. 기존 `index.html`, `ingredients.html`, `processing.html`, `golden.html`, `enhancement.html`을 교체합니다. 4개의 옛 도감 주소는 새 위키 관련 시설로 자동 이동합니다.
4. 기존 효율 계산기에 사용되던 `main.js`는 더 이상 사용하지 않으므로 삭제해도 됩니다.
5. GitHub에서 **Commit changes**를 누르고 배포 완료 후 `Ctrl + Shift + R`로 새로고침합니다.

## 구성 파일

- `index.html` — 새 메인 레이아웃 및 검색 UI
- `style.css` — 다크 모던 위키 디자인 + 반응형 UI
- `wiki.js` — 탐색, 검색, 제작법 카드, 재료 툴팁, 판매가 비교
- `data.js` — 위키 레시피 데이터. 오프라인에서도 열리게 JS 형식으로 함께 제공
- `data.json` — 같은 데이터의 편집하기 쉬운 JSON 버전
- `assets/` — 기존 아이콘 + 첨부받은 4개 시설 간판 + 영혼 8종 + 계약서 4종
- `ingredients.html`, `processing.html`, `golden.html`, `enhancement.html` — 기존 주소 리디렉션

## 재료 미리보기

재료 칸에 마우스를 올리면 *재료 이름·수량·하위 제작법*이 표시됩니다. 재료를 **클릭/터치**하면 독립된 아이템 상세 페이지에서 제작법과 사용처를 볼 수 있습니다.

## 자료와 확인 사항

- 일반/황금 요리 판매가와 레시피, 농작물 가공 5개 구역은 직전 v34 자료를 기반으로 옮겼습니다.
- 영혼 계약서는 재료별 영혼 **각 1개**. 수상한 각인석은 조각 **5개**로 공식 제작 시설 자료를 대조했습니다.
- 강화 횃불의 하위 횃불 제작법은 기존 계산기 데이터에 포함된 내용입니다.
- `수상한 각인석`과 `수상한 각인석 조각`은 사용자가 아이콘을 올리지 않았으므로 글자 기반 자리표시자로 나타납니다. 실제와 다른 그림을 임의로 사용하지 않았습니다.
- **효율 비교**의 현재 기능은 **판매가 및 재료 직접 비교**입니다. 가격만으로 ST 효율·순수익의 우열을 판단하지 않습니다.

자료 참고: [띵타이쿤 공식 제작 시설 위키](https://wiki.ddingtycoon.kr/ko/articles/%EC%A0%9C%EC%9E%91-%EC%8B%9C%EC%84%A4-804e71dc) / [세레니티 아이템](https://wiki.ddingtycoon.kr/ko/articles/%EC%84%B8%EB%A0%88%EB%8B%88%ED%8B%B0-%EC%95%84%EC%9D%B4%ED%85%9C-85e4c935)

※ 이 사이트는 비공식 팬 위키입니다.

## v5 — 도구/무기 제작시설

채광 작업장에 **도구/무기 제작시설**을 추가했습니다.

1. 세이지 도구 4종
2. 보조 도구: 육식 동물 덫, 드릴, 고급 드릴, 나무 어선 획득권, 어선 수리 키트 제작법 3가지
3. 모듈: 커피 관련 모듈, 광채 생성기, 화석 제작대, 보석 세공대, 테라리움, 어항, 형광 광산/모루
4. 체력 포션 4종
5. 커피 컵 2종

* 사용자가 전달한 80개 아이템 이미지 원본을 `assets/tools/`에 저장했습니다. 원본을 손상시킬 수 있는 자동 배경 제거는 하지 않았습니다.
* **영혼 가죽 공방 모듈**은 아이콘만 있고 제작법이 없어 '제작법 미등록' 상태로 보여줍니다.
* 기존의 **어선 수리 키트**는 제작법 세 가지를 그대로 각각 표시합니다.
* 중급/상급 광채 생성기 레시피의 전 단계 아이템은 사용자가 각각 '하급 광물 생성기'/'중급 광물 생성기'라고 적었기에 표시는 원문대로 유지하고, 동명 아이템 상세 정보는 광채 생성기와 연결했습니다.
* `네더 석영`과 `석영`은 동일한 제공 이미지로 표시하되 레시피의 이름 표기는 바꾸지 않았습니다.
* 사용자가 제공하지 않은 이미지(예: 금 괭이, 일부 생선, 거미줄, 사과)는 글자 아이콘으로 표시해 깨진 이미지 링크를 방지합니다.
* 기존 요리/황금요리/영혼 연성소/효율 비교 및 직접 수정한 문구는 유지합니다.
